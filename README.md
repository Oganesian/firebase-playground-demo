# Portfolio-safe app demos

This is a standalone static demo of the budget tracker and recipe roulette.

It deliberately contains **no** Firebase project configuration, SDK, authentication,
analytics, environment variables, personal finance data, or scraped recipe dataset.
All budget values are fictional and changes live only in the visitor's browser until
they refresh the page.

## Run locally

```powershell
npm install
npm run dev
```

## Build and deploy

```powershell
npm run build
```
